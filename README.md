## 🎯 Project Objective

The objective of this project is to transform employee data into an interactive dashboard that provides insights into:

- Employee attrition
- Overtime status
- Salary distribution
- Employee hiring trends
- Employee demographics
- Department and job-role analysis
- Business travel patterns
- Geographic distribution
- Salary-based filtering

The dashboard is designed to help organizations understand workforce patterns and identify factors that may influence employee retention.

---

# 📌 Dashboard Overview

The dashboard contains the following major analytical components:

- Employee Attrition Breakdown
- Overtime Status Distribution
- Salary Distribution Across Age Groups
- Monthly Employee Hiring Trend
- Interactive Employee Filter Panel
- Active Filter Counter

# 📉 1. Employee Attrition Breakdown

The donut chart shows the distribution of employees based on their attrition status.

### Attrition Distribution

| Attrition Status | Percentage |
|---|---:|
| No | 83.88% |
| Yes | 16.12% |

### Insight

The displayed dataset shows that the majority of employees remain with the organization, while **16.12%** are classified as having left.

Attrition analysis can help organizations investigate employee retention and identify potential areas for improvement.
